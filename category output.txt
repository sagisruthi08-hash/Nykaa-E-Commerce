# 8. Create Product Table

Finally:

```sql
CREATE TABLE Product (
    Product_ID NUMBER PRIMARY KEY,
    Product_Name VARCHAR2(100) NOT NULL,
    Category_ID NUMBER,
    Price NUMBER(10,2),
    Stock NUMBER,
    Brand VARCHAR2(100),

    CONSTRAINT fk_product_category
    FOREIGN KEY (Category_ID)
    REFERENCES Category(Category_ID)
);
```

Because this is a `CREATE TABLE` statement, **there is no table output**. Oracle will show something similar to:

```text
Table PRODUCT created.
```

### 🔗 Your relationship

Your two tables are now connected like this:

```text
CATEGORY

Description
       │
       │ 1 : Many
       ↓

Product_Name

Brand
```
